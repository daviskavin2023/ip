# 3040-穿透优选-tunnel

> **Cloudflare Tunnel 智能优选与高可用调度中心**
>
> 专为解决家庭宽带无公网 IPv4、仅有公网 IPv6 且 80/443 被阻断环境下，Cloudflare Tunnel 穿透反代延迟高（250ms+）、丢包严重（15%+）、国内运营商对 UDP QoS 限速痛点而设计的全自动加速体系。

---

## 🎯 核心解决诉求

1. **业务域名完全保持不变**：`https://bgy.808608.xyz` 原生 443 访问，用户无感知。
2. **非独占域名精准隔离**：基于 **Cloudflare for SaaS**，仅接管指定二级域名加速，主域名 `808608.xyz` 下的其他二级记录（如外部 VPS、邮件服务等）完全不受干扰。
3. **多项目未来自动复用**：未来新增任何 Tunnel 穿透业务（如 3041、3042 等），只需在配置中心声明即可自动纳入加速池。
4. **家庭网络真实环境优选**：部署于 PVE1 CT104（`cf-tunnel` 容器，IP `10.10.10.160`），基于家庭宽带真实出口并发测速，智能适配家庭网络。
5. **绝对高可用与零断联兜底**：高频轻量健康心跳检测，主 IP 异常时自动切入备用优选 IP，极端情况下自动回滚官方线路，业务绝不断联。
6. **可视化 Web 控制台**：符合 `yulaiwo-ui-management` 规范，暗夜蓝主题，无外部字体依赖。
